# 法务职责与工单分配

## 处理规则

普通法务只能查看、处理 `legalBpId` 明确分配给自己的工单。列表、分组数量、我的记录和详情采用相同权限边界；创建者字段或历史 `ownerId` 不授予普通法务处理权限。普通业务用户仍可查看自己提交的工单。

人工法务流程：申请人已绑定的钉钉身份 → 有效部门及父部门 → 已启用职责规则 → 唯一启用的普通法务。无有效组织信息、无规则、无可用处理人或多个范围指向不同处理人时，`legalBpId=null`，进入共享领导待分配队列。模型输出的法律领域和申请人自填的部门名称不参与指派。

同一部门链采用最具体的已配置范围；多部门分别匹配，只有结果指向同一人时自动分配。职责配置只影响之后的新工单和 AI 转人工，不自动重派历史工单。

领导账号：`xin.yan`（保持现有管理员角色）、`junfang.zhao`（法务领导）。二者通过已有角色权限查看共享队列；不选择数据库中的“第一位领导”独占兜底工单。未开通的领导账号须先通过成员管理预开通并绑定 CAS 身份。

AI 自助处理先受既有风险路由约束；允许 AI 处理时，再按本轮问题意图选择执行能力。进入人工法务时，咨询与合同使用同一分配逻辑。CRM A1 保持已验签的 `currentNodeAssignee` 显式指派契约，不被部门规则覆盖，不自动建钉钉群。

## AI 意图路由

咨询消息接口 `POST /api/projects/:id/messages` 的 `capability` 可选 `auto`（默认）、`general`、`law_search`、`similar_case`。前端默认“自动识别”，仍可手动指定。该字段不改变风险分级或人工分配权限。

| 意图 | 执行能力 | 边界 |
| --- | --- | --- |
| 一般概念解释、给定材料整理、文字起草 | 通用法务咨询 | 不调用外部法律检索 |
| 法规检索、现行规则、法条与法律依据核验 | AI 搜法 | 通过 DSH 读取权威正文后生成报告 |
| 判例、相似案例、裁判结果检索比较 | AI 类案 | 受案例工具与数据源可用性约束 |

分类仅使用当前任务及有限会话上下文，输出限于以上三种 AI 能力，不接收法务人员或部门标识。分类结果在运行认领后持久化到 `ConsultationRun.capability`，同一运行重试复用已选能力；自动识别成功会留下固定工单事件，SSE 的 `message_start.capability` 返回实际执行能力。

分类服务失败或输出无效时返回安全的 503 提示，不降级为未经检索的通用回答。分类期间工单状态或运行发生变化时停止执行。没有新增数据库表、迁移或额外内容哈希。

管理员在“成员管理 → 分配与路由”查看独立的 AI 与人工处理路径，搜索人员并核验职责范围。旧法务专业领域标签不再提供配置入口，也不参与自动分配。应用目录规则前需确认；“待应用”不等于已生效，“待完善”不参与分配。

## 配置生效与数据安全

1. 部署前执行新增迁移 `20260913060000_add_legal_assignment_rules`。仅增加组织关系和规则数据结构，不迁移历史工单、不提升账号角色。
2. 同步钉钉通讯录，保存完整部门树和员工的多个部门 ID。通讯录、部门、绑定和批次结果在同一事务内提交；同步失败不覆盖上一成功快照。
3. 管理员核对职责预览，点击“确认应用已核验职责”。账号、姓名、角色或部门不符的范围保持未启用；其余范围以真实部门 ID 和系统用户 ID 落库。
4. 领导进入工单管理，勾选“仅看待领导分配”，在详情页选择法务并确认分配；管理员可从数据看板的“工单管理”进入。队列包含未分配、领导/管理员接手以及处理人停用或已不再是普通法务的未完成工单。普通 BP 无权查询候选人接口、读取待分配池或直接认领。
5. PATCH 指派、转派、领导认领及领导首次正式回复均将指派与通知任务同事务提交，入队失败回滚本次变更。新工单无处理人时不建钉钉群；首次指派后由后台任务补建，使用固定工单去重键。外部钉钉故障不改变已提交归属，保留重试及异常记录；未绑定钉钉的处理人会留下需人工建群的事件。

接口：

- `GET /api/admin/members/bp-responsibilities`：管理员查看清单及生效前校验结果。
- `POST /api/admin/members/bp-responsibilities/apply`：管理员应用已核验规则并记录审计。不会创建账号、更改角色或重派历史工单。
- `GET /api/projects?assignment=pending`：领导/管理员待分配筛选，支持既有分组分页；普通 BP 返回 403。
- `GET /api/projects/assignees`：领导/管理员查询启用的法务候选人，只返回 ID、姓名、角色。
- `POST /api/projects/:id/transfer`：领导/管理员指派法务。

原 `bp-domains` 仅保留为专业领域标签，不再参与自动指派。运行时按规则表匹配，不按人名、拼音推测身份，也不进行模糊部门名称授权。

## 上线验收

验证新建命中、未命中和多部门冲突三条链路；确认普通法务列表与详情均不可访问未分配或分配给他人的工单；由领导指派后检查目标法务可见、其他法务不可见；检查钉钉首次建群及 CRM 不建群边界。

构建和本地测试通过不代表规则已在线上启用；须完成迁移、通讯录同步、管理员应用以及真实账号浏览器验收。
