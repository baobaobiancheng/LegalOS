# 法务AI平台（LegalPlatform）业务功能总表

> 版本：V1.0 | 日期：2026-07-31 | 状态：待业务确认
> 
> 说明：本文档按五层（法务端 / 业务端 / 管理端 / 系统对接 / 平台基础）梳理平台全部业务功能，标注实现状态，用于人员分工与排期规划。

---

## 一、法务端（Legal OS）

面向法务 BP 与法务负责人的核心工作台。

| 序号 | 功能模块 | 功能说明 | 状态 | 优先级 | 建议负责人 |
|:---:|----------|----------|:---:|:---:|------------|
| 1.1 | **工单管理** | 工单全生命周期管理：创建（业务咨询 / 合同协作 / 法律检索 / 文书生成四类）、状态流转（分析中 → 待复核 → 已回传 / 已取消）、风险分级（P0/P1/P2）、工单列表按状态分组、工单转派、最近工作 | 🔴 待开发 | P0 | |
| 1.2 | **业务咨询处理** | 接收业务端升级的 P1/P0 工单，AI 辅助分析并生成初稿，法务 BP 复核后正式回传业务端 | 🔴 待开发 | P0 | |
| 1.3 | **合同协作审阅** | 接收业务端提交的合同工单，AI 自动进行条款风险审查，法务 BP 审阅定稿后回传 | 🔴 待开发 | P0 | |
| 1.4 | **法规检索** | 对接国家法律法规数据库，支持关键词检索 + 法条定位 + AI 三段式法律释义（法条原文 / 法律分析 / 需确认事实），附带法规来源追溯与效力状态标注 | 🔴 待开发 | P0 | |
| 1.5 | **技能库** | 6 大技能组（合规法务 / 合同与交易 / 劳动法务 / 争议法务 / 法律研究 / 知识运营）共 18 项技能，工单创建时关联技能以优化 AI 处理效果 | 🔴 待开发 | P0 | |
| 1.6 | **定时任务** | 法务周报自动生成、待回传工单每日提醒、合同协作审阅进度提醒、法规更新周报、自定义定时任务（支持手动执行、启用/暂停、执行记录查看） | 🔴 待开发 | P0 | |
| 1.7 | **数字分身配置** | 设置分身名称与人设、回复口径与边界、P2 授权范围、自动升级条件规则、默认引用知识库条目、版本管理（自动递增 + 历史追溯）、安全试运行（测试问题预览答复） | 🟡 v0.2.0 | — | |
| 1.8 | **数字分身复核** | 法务 BP 对数字分身直答复进行抽检复查：直接采纳 / 修改后采纳 / 升级为人工处理 | 🟡 v0.2.0 | — | |
| 1.9 | **企业知识库** | 知识条目 CRUD，按"受控发布"与"待审核"管理状态，工单处理时可引用企业知识条目 | 🟡 v0.2.0 | — | |
| 1.10 | **个人知识库** | 法务个人私有知识空间，支持上传/拖拽文件（.docx / .pdf / .txt），本地自动识别脱敏 6 类敏感信息（手机号 / 邮箱 / 身份证 / 银行卡 / 金额 / 订单号），脱敏预览确认后入库；可提交至企业库经法务负责人审核后发布 | 🟡 v0.2.0 | — | |
| 1.11 | **知识沉淀** | 已回传的优质工单自动进入待沉淀队列，经法务负责人审核后写入企业知识库，形成"工单→沉淀→复用"的闭环 | 🟡 v0.2.0 | — | |

## 二、业务端（Business OS）

面向业务人员（销售 / 采购 / 市场等），无需跳转即可获取法务支持。

| 序号 | 功能模块 | 功能说明 | 状态 | 优先级 | 建议负责人 |
|:---:|----------|----------|:---:|:---:|------------|
| 2.1 | **法律咨询** | 业务人员用自然语言描述法律问题→系统自动判断风险等级→P2 常规问题 LLM 即时直答（1 分钟内）/ P1+P0 高风险自动升级创建法务端工单→法务处理结果自动回传至业务端原始会话；支持多轮追问与对话历史保留；AI 答复按"核心结论 → 重点风险 → 建议动作 → 需补充确认"四段式输出 | 🔴 待开发 | P0 | |
| 2.2 | **合同助手** | 选择合同模板（渠道合作协议 / 技术服务合同 / 保密协议）→ 输入关键要素（对方主体、金额、期限等）→ AI 生成合同草稿 → 支持下载 .docx 或发起法务审阅 → 本地编辑后上传回传继续审阅 → 法务定稿回传下载 | 🔴 待开发 | P0 | |
| 2.3 | **我的记录** | 按时间倒序展示所有咨询与合同记录，支持按状态筛选（处理中 / 已回传 / 已取消），点击继续追问或补充信息，查看完整对话历史，已完成的合同草稿下载，支持导出 PDF | 🔴 待开发 | P0 | |
| 2.4 | **满意度评价** | 业务人员对 AI 直答和法务人工答复分别评分，作为数字分身效果和法务 BP 工作质量的衡量指标 | 🟡 v0.2.0 | — | |

| 3.6 | **个人设置** | 各角色修改个人信息、显示名称 | 🔴 待开发 | P2 | |

## 四、系统对接

与外部系统的集成，采用 Adapter 模式设计，MVP 阶段使用 Mock 实现跑通流程，后续替换为真实接口。

| 序号 | 对接系统 | 功能说明 | 状态 | 优先级 | 建议负责人 |
|:---:|----------|----------|:---:|:---:|------------|
| 4.1 | **钉钉集成** | 工单创建后自动在钉钉创建协作群，拉入法务 BP + 业务人员 + 相关接口人；群公告同步工单链接和关键节点；工单状态变更与超时通过钉钉通知相关责任人 | 🔴 待开发 | P0 | |
| 4.2 | **CRM 集成** | 工单创建时自动带入 CRM 业务上下文（客户名称 / 商机编号 / 合同编号 / 业务类型）；法务处理结果回写 CRM 对应记录；工单状态变更同步 CRM 法务协同状态 | 🔴 待开发 | P0 | |
| 4.3 | **国家法律法规数据库** | 对接 flk.npc.gov.cn 搜索接口，下载并解析法规 DOCX 原文，按法条号精确定位条款 | 🔴 待开发 | P0 | |
| 4.4 | **数字分身底层能力** | 对接李帅团队数字分身接口，本平台负责配置管理与业务集成，不做分身底层开发 | 🟡 v0.2.0 | — | |

| 5.1 | **统一登录** | 单一登录入口，JWT 双 Token 认证（accessToken 15 分钟置内存 + refreshToken 24 小时 httpOnly Cookie），5 次失败锁定 30 分钟，速率限制 5 次/分钟，Refresh Token 旋转防重放，登录审计日志 | 🟢 已完成 | P0 | — |

| 5.3 | **三端 UI 框架** | Apple 风格界面（Aurora 渐变背景 + 毛玻璃卡片 + 弹性动画），法务端 / 业务端 / 管理端三套导航与骨架页面，403 无权限页 | 🟢 已完成 | P0 | — |
