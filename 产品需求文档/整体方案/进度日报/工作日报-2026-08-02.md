## 二、关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| Markdown 渲染 | markstream-vue | 自动流式渲染，预留 Mermaid 图表 |
| 风险判定 | LLM 意图识别 | 替代关键词匹配，准确率更高 |
| 文件上传 | 客户端读取 + 拼入 prompt | 无需后端存储，Codex 原生解析 docx/pdf |
| Word 下载 | docx 库（真 .docx） | WPS 渲染质量好于 HTML-as-doc |
| PDF 下载 | html2pdf.js | 浏览器引擎渲染中文，A4 纸张 |
| 输入栏 | position:sticky | 滚动时吸附视口底部，豆包同款 |
| Windows 兼容 | cmd.exe /c + stdin 管道 | 避免 bash 依赖，同时兼容 Linux |
