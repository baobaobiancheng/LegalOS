
# 法规详情接口 — 三种返回格式说明

> 接口：`lawstar_data_professional_detail`  
> 示例法规：《中华人民共和国民法典》（lawId = `8F80C43687B13EA1FB8DB364A6245F49`）

---

## 总览

调用 `lawstar_detail(lawId)` 返回完整响应结构如下（省略 HTML 正文以控制篇幅）：

```json
{
  "lawName": "中华人民共和国民法典",
  "rjs8": "8F80C43687B13EA1FB8DB364A6245F49",
  "issuingOrgan": "全国人民代表大会",
  "releaseYearMonthDate": "2020年05月28日",
  "implementYearMonthDate": "2021年01月01日",
  "issuingNo": "中华人民共和国主席令第45号",
  "timeliness": "现行有效",
  "hasCompare": "1",
  "hisgroup": [],
  "enclosure": [],
  "basisList": [],
  "anchorNumber": "",
  "tocItem": [ /* 8 编级目录树，多层嵌套 children，见下方 */ ],
  "downdetailurl": "https://api.law-star.com/api/lawData/professional/downdetail?data=...",
  "downdetailurlpdf": "https://api.law-star.com/api/lawData/professional/downdetailpdf?data=...",
  "lawSourceContent": "<p style='text-align:center'><strong>中华人民共和国民法典</strong></p>..."
}
```

其中原文相关内容有三种形式：**HTML 正文**、**Word 下载**、**PDF 下载**。

---

## 形式一：HTML 正文（`lawSourceContent`）

### 适用场景

程序处理、搜索高亮、网页展示、文本分析。

### 格式特征

- 完整 HTML 字符串，含 `<p>`、`<strong>`、`<span>` 等标签
- 法规正文 + 目录 + 主席令原文
- 民法典正文 **175,170 字符**

### 开头部分

```html
<p style='text-align:center'><strong>中华人民共和国民法典</strong></p>
<p><br/></p>
<p style='text-align:center'><strong>中华人民共和国主席令第45号</strong></p>
<p><br/></p>
<p>　　《中华人民共和国民法典》已由中华人民共和国第十三届全国人民代表大会
第三次会议于2020年5月28日通过，现予公布，自2021年1月1日起施行。</p>
<p><br/></p>
<p style='text-align:right'>中华人民共和国主席 习近平</p>
<p style='text-align:right'>二○二○年五月二十八日</p>
<p><br/></p>
<p style='text-align:center'><strong>中华人民共和国民法典</strong></p>
<p><br/></p>
<p style='text-align:center'><strong>（2020年5月28日第十三届全国人民代表大会第三次会议通过）</strong></p>
```

### 目录部分（HTML 中以纯文本排列）

```

　　第一章　基本规定
　　第二章　自然人

　　...
```

### 正文条文示例


### 代码示例

```python
from baijian_mcp_client import BaijianMCPClient

client = BaijianMCPClient()
detail = client.lawstar_detail("8F80C43687B13EA1FB8DB364A6245F49")

html = detail["lawSourceContent"]

# 去除 HTML 标签得到纯文本
import re
text = re.sub(r'<[^>]+>', '', html)
text = text.replace('\r', '\n').strip()

# 保存为文件
with open("民法典.html", "w", encoding="utf-8") as f:
    f.write(html)
```

## 形式二：Word 文件下载（`downdetailurl`）

### 适用场景

离线审阅、打印、本地归档。

### 格式特征

| 属性 | 值 |
|------|-----|
| 文件格式 | `.docx`（ZIP 压缩格式，文件头 `PK\x03\x04`） |
| Content-Type | `application/octet-stream` |
| 民法典文件大小 | **113,196 bytes**（约 111 KB） |
| 下载方式 | HTTP GET，需携带鉴权头 |

### 完整下载 URL

```
https://api.law-star.com/api/lawData/professional/downdetail
  ?data=293E23E44C9E1F734964AB3C9F35F82F10A1583952B7B75567A55C7996CFF276
         D84DE95ED71A01029D84E650E7371B2E4511151775D07F41C5522497075E7A05
         6C13F7436298475A3A4841BEE0EAF582862FC4340B66926C509E25A3D5DE49D
         800B973D4E4311AE6
```

> `data` 参数为加密后的文件标识，每次调用 detail 接口返回的 URL 相同（同一 lawId 缓存）。

### 代码示例

```python
import requests
from baijian_mcp_client import BaijianMCPClient

client = BaijianMCPClient()
detail = client.lawstar_detail("8F80C43687B13EA1FB8DB364A6245F49")

url = detail["downdetailurl"]
headers = {
    "X-App-Key": client.app_key,
    "X-App-Secret": client.app_secret,
}

resp = requests.get(url, headers=headers)
with open("中华人民共和国民法典.docx", "wb") as f:
    f.write(resp.content)

print(f"下载完成: {len(resp.content)} bytes")
```

## 完整字段参考

| 字段 | 类型 | 民法典值 | 说明 |
|------|------|----------|------|
| `lawName` | string | `中华人民共和国民法典` | 法规名称 |
| `rjs8` | string | `8F80C436...` | 法规唯一 ID（32 位 hex） |
| `issuingOrgan` | string | `全国人民代表大会` | 发文机关 |
| `releaseYearMonthDate` | string | `2020年05月28日` | 发布日期 |
| `implementYearMonthDate` | string | `2021年01月01日` | 实施日期 |
| `issuingNo` | string | `中华人民共和国主席令第45号` | 文号 |
| `timeliness` | string | `现行有效` | 时效性 |
| `hasCompare` | string | `"1"` | 是否支持版本比对 |
| `hisgroup` | array | `[]` | 历史版本列表 |
| `enclosure` | array | `[]` | 附件列表 |
| `basisList` | array | `[]` | 相关依据 |
| `anchorNumber` | string | `""` | 锚点信息 |
| `tocItem` | array | 8 项（见下） | 法规目录树 |
| `lawSourceContent` | string | HTML, 175,170 字符 | 法规正文 |
| `downdetailurl` | string | HTTPS URL, 274 字符 | Word 下载链接 |
| `downdetailurlpdf` | string | HTTPS URL, 277 字符 | PDF 下载链接 |

### `tocItem` 目录树结构

民法典目录为 **8 个编级节点**，每个节点包含多层嵌套 `children`：

```
中华人民共和国民法典
├── 第一编  总则
│   ├── 第一章  基本规定
│   ├── 第二章  自然人
│   │   ├── 第一节  民事权利能力和民事行为能力
│   │   ├── 第二节  监护
│   │   ├── 第三节  宣告失踪和宣告死亡
│   │   └── 第四节  个体工商户和农村承包经营户
│   ├── 第三章  法人
│   │   ├── 第一节  一般规定
│   │   ├── 第二节  营利法人
│   │   ├── 第三节  非营利法人
│   │   └── 第四节  特别法人
│   ├── 第四章~第十章 ...
├── 第二编  物权
│   ├── 第一分编~第五分编 ...
├── 第三编  合同
│   ├── 第一分编~第三分编 ...
├── 第四编  人格权
├── 第五编  婚姻家庭
├── 第六编  继承
├── 第七编  侵权责任
└── 附则
```

每个节点 JSON 结构：

```json
{
  "id": "section0",
  "text": "第一编  总则",
  "indentLevel": 0,
  "children": [ /* 子节点 */ ]
}
```

| 缩进级别 | 含义 |
|:--------:|------|
| `0` | 编 |
| `1` | 分编 |
| `2` | 章 |
| `3` | 节 |

## 三种形式对比

| | HTML 正文 | Word 下载 | PDF 下载 |
|------|:--:|:--:|:--:|
| 字段 | `lawSourceContent` | `downdetailurl` | `downdetailurlpdf` |
| 获取方式 | 直接返回 | HTTP GET 下载 | HTTP GET 下载 |
| 格式 | HTML 字符串 | `.docx`（ZIP） | PDF 1.7 |
| 民法典大小 | 175 KB | 111 KB | 488 KB |
| 需额外请求 | 否 | 是 | 是 |
| 需鉴权 | — | `X-App-Key` + `X-App-Secret` | 同左 |
| 目录结构 | HTML 中文本 | 有 | 有 |
| 适合 | 程序处理、网页展示 | 离线编辑、归档 | 打印、分发 |
