# 技能库 A/B 输出评估用例（门禁 #11）

Generated by /plan-eng-review on 2026-08-04 | 工程评审决策 #9（OV#7）：产品价值在于技能是否改变 AI 输出，输出质量是显式验收项。

## 目的

验证 3 个 seed 技能（数据合规评估 / 合同风险审查 / 员工关系咨询）的 prompt 口径是否**明显优于**通用咨询 prompt。由法务 BP 彭宇欣评审，技能口径答复明显更优方为达标。

## 跑法（每个案例跑两遍）

1. **技能模式**：业务端咨询页选择对应技能 → 提交问题 → 保存 AI 答复
2. **通用模式**：同一问题不选技能（默认"通用法务咨询"）→ 提交 → 保存 AI 答复
3. 两份答复并排填入下表，彭宇欣按 4 个维度打分（1-5 分）

## 对比案例（3 题，各覆盖一个 seed 技能）

| # | 技能 | 问题 |
|---|------|------|
| 1 | 数据合规评估 | 我们准备收集用户手机号用于营销推送，需要评估合规风险 |
| 2 | 合同风险审查 | 帮我审查合同条款：违约金为合同总价 50%，且知识产权全部归对方所有 |
| 3 | 员工关系咨询 | 员工试用期考核不合格，公司想解除劳动合同，需要什么流程 |

## 评审表（每案例一份）

| 维度 | 技能模式 (1-5) | 通用模式 (1-5) | 说明 |
|------|:---:|:---:|------|
| 专业性 | | | 是否呈现领域专家级分析（法条援引/审查要点/操作流程） |
| 结构 | | | 是否按技能规定的输出结构（风险点/法律依据/整改建议 等三段式） |
| 可执行性 | | | 建议是否可直接落地（步骤/文书/时间节点） |
| 法律依据准确性 | | | 援引条文是否真实准确、对号入座 |

**判定**：3 个案例中 ≥2 个案例技能模式总分 ≥ 通用模式 + 3 分 → 门禁通过。
