# 意图分类规则（LLM Risk Assessment）

> 版本：V1.0 | 日期：2026-08-02 | 关联：业务法律咨询模块

---

## 一、概述

业务端法律咨询在创建工单前，先调用 LLM 对用户问题进行意图识别和风险分级，根据分级结果决定处理路由。

```
用户提问 → LLM 意图分类 → P0/P1/P2 → 路由决策
```

- **P2**：LLM 直答（SSE 流式），即时返回业务端
- **P1**：创建法务端工单，通知法务 BP 人工处理
- **P0**：同 P1 + 紧急标记 + 高优先级钉钉通知

---

## 二、分类 Prompt

```text
判断以下法律咨询问题的风险等级，只回复一个标签（P0/P1/P2），不要任何解释：

P0（紧急）：涉及刑事犯罪、监管执法调查、紧急法院禁令、重大安全事故
P1（重要）：涉及无限责任、数据出境、跨境传输、个人信息保护、诉讼仲裁、并购股权、竞业限制
P2（常规）：其他一般法律问题，合规咨询，合同条款询问，政策了解

用户问题：{用户输入}

风险等级：
```

---

## 三、三级风险定义

### P0 — 紧急

| 触发场景 | 示例 |
|----------|------|
| 刑事犯罪风险 | "我们公司可能涉及商业贿赂刑事调查" |
| 监管执法调查 | "市场监管局来查我们的产品了" |
| 紧急法院禁令 | "竞品拿到了临时禁令，要求我们立即下架" |
| 重大安全事故 | "工厂出了安全事故，安监部门介入了" |

**路由**：`legalbp` — 创建工单 + 紧急标记 + 高优先级钉钉通知

### P1 — 重要

| 触发场景 | 示例 |
|----------|------|
| 无限责任条款 | "客户要求把责任上限改成无限责任" |
| 数据出境 | "要把用户数据传给海外母公司" |
| 跨境传输 | "涉及跨境数据传输到欧洲" |
| 个人信息保护 | "收集用户人脸信息用于打卡" |
| 诉讼仲裁 | "收到法院传票了怎么办" |
| 监管合规 | "银保监要来检查我们的业务流程" |
| 并购股权 | "收购一家公司，股权结构怎么设计" |
| 竞业限制 | "核心员工跳槽到竞品，竞业协议能约束吗" |

**路由**：`legalbp` — 创建工单，正常流程通知法务 BP

### P2 — 常规

| 触发场景 | 示例 |
|----------|------|
| 合规咨询 | "促销活动写'最终解释权归本店所有'合规吗" |
| 合同条款询问 | "客户要求把付款账期从30天改到60天，能接受吗" |
| 政策了解 | "新出的个保法对我们业务有什么影响" |
| 一般法律问题 | "劳动合同到期不续签需要赔偿吗" |
| 商务条款协商 | "对方要加保修期，行业惯例是多久" |

**路由**：`llm` — AI 直答，四段式输出，SSE 流式返回

---

## 四、降级策略

| 场景 | 行为 | 原因 |
|------|------|------|
| LLM 分类器不可用 | 默认 P1 → 人工处理 | 安全优先：宁可阻塞不放行 |
| LLM 返回内容不含 P0/P1/P2 | 默认 P2 → AI 直答 | 正常问题不给用户添堵 |
| 分类超时（10秒） | 默认 P1 → 人工处理 | 超时通常意味着服务异常 |

## 五、技术实现

```typescript
// api/src/common/services/llm-risk.service.ts

async assess(query: string): Promise<{ risk: RiskLevel; route: ProjectRoute }> {
  const prompt = `判断以下法律咨询问题的风险等级，只回复一个标签（P0/P1/P2），不要任何解释：

P0（紧急）：涉及刑事犯罪、监管执法调查、紧急法院禁令、重大安全事故
P1（重要）：涉及无限责任、数据出境、跨境传输、个人信息保护、诉讼仲裁、并购股权、竞业限制
P2（常规）：其他一般法律问题，合规咨询，合同条款询问，政策了解

用户问题：${query}

风险等级：`;

  try {
    const result = await this.codexService.execute(prompt, {
      maxTokens: 5,      // 只要标签，不需要长回复
      timeout: 10_000,   // 10秒超时
    });
    const trimmed = result.trim().toUpperCase();
    if (trimmed.includes('P0')) return { risk: 'P0', route: 'legalbp' };
    if (trimmed.includes('P1')) return { risk: 'P1', route: 'legalbp' };
    return { risk: 'P2', route: 'llm' };
  } catch (error) {
    this.logger.error(`LLM risk assessment failed, defaulting to P1/legalbp: ...`);
    // 安全优先：分类失败默认升级人工处理
    return { risk: 'P1', route: 'legalbp' };
  }
}
```

- **调用方式**：`codex exec` CLI，stdin 输入 prompt
- **并发控制**：受 CodexService 50 信号量限制，超出的请求排队等待
- **每条消息独立判定**：不缓存，追问也重新分类。追问触发 P0/P1 时自动升级路由
- **大小写兼容**：`result.trim().toUpperCase()` 后再匹配，兼容 `p0`/`P0` 等各种写法
