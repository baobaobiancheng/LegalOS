> 面向:业务人员、法务 BP、法务负责人、系统管理员。

- **登录**:密码登录 + 公司账号登录(CAS)双入口。预发/生产启用 `CAS_ENFORCED` 后仅 CAS 入口(本地开发密码入口仍可用)。

## 二、当前已实现功能总览

### 1. 业务端(role=`business`)
| 功能 | 说明 |
|---|---|
| **法律咨询** | 发起咨询 → AI 风险分类 → 低风险直接 AI 流式回答(思考+正文),高风险自动升级人工;支持多轮追问 + DOCX/TXT/MD 附件上传进模型 |
| **合同助手** | 基于合同模板(AI服务/NDA/技术开发等)起草合同 → 提交法务审查 |
| **我的记录** | 历史咨询/合同记录列表 + 详情页;继续追问、下载答复(Word 导出)、升级人工 |

### 2. 法务端(role=`legal_bp` / `legal_lead`)
| 功能 | 说明 |
|---|---|
| **工单管理** | 待处理/待复核/已回传/已取消等状态的工单列表与详情 |
| **法务回传** | 在待复核工单详情页输入回传意见,法务正式回复业务端 |
| **技能库** | 查看/维护 6 大技能组 18 项法务技能,支持提交/审核/下架(含数据合规、合同风险审查、员工关系等) |
| **钉钉协作**(后端) | 工单创建自动拉钉钉群同步 |

### 3. 管理员(role=`admin`)
| 功能 | 说明 |
|---|---|
| **成员管理** | 钉钉通讯录同步、用户绑定/解绑、BP 领域映射 |
| **Outbox 运维** | `admin/outbox` 队列状态(异步任务:钉钉建群/回写) |

### 4. 公共能力(全平台)
- **风险分级**:确定性规则下限 + AI 模型判定,刑事/数据出境/诉讼等高风险**不可被注入降级**,自动进人工
- **多轮上下文**:会话内历史问题/答案参与后续回答
- **直连大模型网关**:glm-5-2 推理模型,思考+正文双路流式(2026-08-12 起风险分类也走直连,不再经 Codex CLI)
