# CAS 接入 — 外部协作清单(一步一步照着做)

> 给没做过 CAS 对接的你。你要找 2 拨人 + 自己做 1 件事:**郭广旭**(CAS 权限)、**自己**(CAS 后台建项目),SRE 域名**可延后**。
>
> **先记住三件事(省掉一大半麻烦)**:
> 1. **本地开发不需要 SRE**:默认 `CAS_BYPASS=true` 完全不碰真实 CAS;要测真实流只需自己加 hosts(`10.100.123.74 cas-pre.100credit.cn`),出站是内网正常访问。
> 2. **对内使用可以先不要域名**:CAS 的「项目认证登录URL」可以是**内网 IP + 端口**(如 `http://192.168.162.170:5173/login`),你已经用这个 IP 访问过前端。
> 3. 只有**上生产前**才需要 SRE 配域名 + HTTPS(ticket 明文走内网的风险收口)。

---

## 第 1 步:找郭广旭开 CAS 后台管理权限(必需,最先做,要等)

**联系渠道**:企业微信/钉钉搜「郭广旭」。

**话术模板(直接复制改名字)**:
> 郭老师您好,我是法务AI平台(LegalOS)的负责人包正和。我们要接入公司 CAS 统一登录,需要在 CAS 后台创建项目并配置,麻烦帮我开通 CAS 后台的管理权限。项目名:法务AI平台(LegalOS),项目 code 想用 `legalos`。谢谢!

**他需要给你的**:
1. **CAS 后台管理权限** —— 让你能看到「项目管理」「授权管理-角色列表」菜单
2. (可顺带要)**open API 的调用 token** —— 二期同步用户用,一期可以先不要

**确认成功**:登录 CAS 后台,能看到项目/角色相关菜单。

---

## 第 2 步:自己建项目 + 开通账号(拿到权限后)

### 2a. 建项目

进入 CAS 后台 → **项目管理 → 新建项目**,填:

| 字段 | 填什么 | 说明 |
|------|--------|------|
| 项目名称 | 法务AI平台(LegalOS) | 对外展示 |
| 项目简称(code) | `legalos` | **双方约定,联调时一致**;登录身份校验用 |
| 应用图标 | 可传 LegalOS logo(可选) | |
| **项目认证登录URL** | `http://192.168.162.170:5173/login` | **最关键**——CAS 生成 ticket 后 302 跳回这里;内网 IP 即可,不用域名 |
| 是否默认开通 | 否 | 不让全员自动有权限 |
| 是否可以申请 | 是 | 内部系统,员工自助申请 |
| 是否对接权限系统 | **否** | 我们只做登录+项目门禁;领域角色平台自己管(设计 P2) |

> **认证登录URL 用 IP 还是域名?**
> - 内网先用 IP:`http://192.168.162.170:5173/login`(零外部依赖)
> - 上生产前换域名 + HTTPS:`https://legalos-pre.100credit.cn/login`(需 SRE,见第 3 步)

### 2b. 配角色

授权管理 → 角色列表 → 为 legalos 项目建:

| 角色 code | 角色名 | 用途 |
|-----------|--------|------|
| `legalos_user` | 法务平台普通用户 | 默认角色 |
| `legalos_admin` | 法务平台管理员 | 可选(不依赖;平台 admin 用 `CAS_ADMIN_USERNAMES` 配) |

> 角色仅为满足 CAS 项目配置/门禁;我们不信任 roleCode 当领域角色(设计 P2)。

### 2c. 开通自己账号

- 在 CAS 后台把你自己(如 `zhenghe.bao`)开通 `legalos` 项目权限 + 授予 `legalos_user` 角色
- **确认成功**:从 CAS 门户能看到 LegalOS 图标,点进去能跳回 `http://192.168.162.170:5173/login?ticket=xxx`

---

## 第 3 步:SRE 域名 + HTTPS(可延后,上生产前做)

**现在可以先跳过。** 上生产前再找 SRE 要 3 件事:

| # | 要什么 | 例子 | 为什么 |
|---|--------|------|--------|
| 1 | **前端 HTTPS 域名** | `https://legalos-pre.100credit.cn` | 换掉认证登录URL 里的内网 IP(ticket 明文风险收口) |
| 2 | **后端 API 域名**(或同域名 `/api`) | 同上域名下 `/api` | 前后端访问 |
| 3 | **后端服务器出网** | pm2 主机能访问 `https://cas-pre.100credit.cn` | 后端调 `/validate` 校验 ticket;防火墙放行 |

**确认成功**:浏览器打开 `https://cas-pre.100credit.cn` 有响应;服务器 `curl https://cas-pre.100credit.cn` 返回非 000。
